# Alexandria Setup Guide\n\n## Prerequisites\n\n- Node.js 18+ \n- pnpm (package manager)\n- Supabase account\n- xAI account (optional, for AI content generation)\n\n## 1. Environment Setup\n\n1. Copy the environment template:\n   ```bash\n   cp .env.example .env.local\n   ```\n\n2. Update the environment variables in `.env.local`:\n   ```env\n   # Supabase Configuration\n   SUPABASE_URL=your_supabase_project_url\n   SUPABASE_ANON_KEY=your_supabase_anon_key\n   \n   # xAI Configuration (optional)\n   XAI_API_KEY=your_xai_api_key\n   \n   # App Configuration\n   VITE_APP_URL=http://localhost:5173\n   ```\n\n## 2. Supabase Setup\n\n### Create a New Supabase Project\n\n1. Go to [supabase.com](https://supabase.com) and create a new project\n2. Get your project URL and anon key from Settings > API\n3. Update your `.env.local` file with these values\n\n### Run Database Migrations\n\n1. Open the Supabase SQL editor\n2. Run the migration script from `app/sql/migration/001_initial_schema.sql`\n3. Run the seed script from `app/sql/seed.sql`\n\n### Alternative: Using Supabase CLI\n\n```bash\n# Install Supabase CLI\nnpm install -g supabase\n\n# Login to Supabase\nsupabase login\n\n# Initialize in your project (optional)\nsupabase init\n\n# Link to your remote project\nsupabase link --project-ref your-project-ref\n\n# Push the schema\nsupabase db push\n```\n\n## 3. xAI Setup (Optional)\n\n1. Create an account at [x.ai](https://x.ai)\n2. Get your API key from the dashboard\n3. Add it to your `.env.local` file\n\n**Note:** If you don't set up xAI, the system will use fallback content for testing.\n\n## 4. Install Dependencies\n\n```bash\npnpm install\n```\n\n## 5. Run the Application\n\n```bash\n# Development mode\npnpm dev\n\n# Production build\npnpm build\npnpm start\n```\n\n## 6. Testing the Application\n\n1. Visit `http://localhost:5173`\n2. Create an account via the \"Sign Up\" page\n3. Complete the onboarding wizard\n4. Access your dashboard\n5. Use the \"Generate Test Content\" button to test AI content generation\n\n## Database Schema Overview\n\nThe application uses the following main tables:\n\n- **profiles** - User profiles linked to Supabase auth\n- **topics** - Available learning topics\n- **user_topics** - User's selected topics (many-to-many)\n- **user_preferences** - User learning preferences\n- **content** - Generated learning content\n- **user_progress** - User's reading progress and ratings\n\n## Features Implemented\n\n✅ **Authentication System**\n- Sign up / Sign in with email\n- Protected routes\n- User profiles\n\n✅ **Onboarding Wizard**\n- Topic selection\n- Learning preferences (frequency, depth, format)\n- Multi-step interface\n\n✅ **Dashboard**\n- User stats and progress\n- Recent content display\n- Settings management\n\n✅ **Content Management**\n- AI-generated content (with xAI integration)\n- Content viewing and rating\n- Progress tracking\n\n✅ **Email System**\n- Email template generation\n- Scheduling system (ready for cron integration)\n- Content delivery via email\n\n## Next Steps for Production\n\n1. **Email Service Integration**\n   - Verify your SUPABASE_URL and SUPABASE_ANON_KEY\n   - Check if your Supabase project is active\n\n2. **Authentication Not Working**\n   - Ensure RLS policies are correctly set up\n   - Check if the `handle_new_user()` function is working\n\n3. **Content Generation Failing**\n   - Verify XAI_API_KEY is correct\n   - Check the xAI API status\n   - Fallback content should still work without API key\n\n4. **Database Errors**\n   - Ensure all migrations have been run\n   - Check that seed data was inserted correctly\n\n### Getting Help\n\nIf you encounter issues:\n\n1. Check the browser console for errors\n2. Check the server logs in your terminal\n3. Verify your environment variables\n4. Ensure all database migrations have been applied\n\n## Architecture Notes\n\nThis application uses:\n\n- **React Router v7** - Full-stack framework with server-side rendering\n- **TypeScript** - Type safety throughout\n- **TailwindCSS v4** - Modern styling\n- **Shadcn/UI** - Consistent component library\n- **Supabase** - Backend-as-a-Service (auth, database, real-time)\n- **xAI API** - AI content generation\n- **Vite** - Fast development and building\n\nThe architecture follows a feature-based structure with clear separation between client and server code, making it easy to scale and maintain.
